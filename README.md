# Портал погодження документів (тест)

Спільне редагування і погодження документів компанією та контрагентами.

- **Сайт:** `index.html` (GitHub Pages, статичний).
- **API:** n8n-воркфлоу «Портал погодження документів — API» (`/webhook/doc-portal-api`, `/webhook/doc-portal-ack`).
- **База:** Google Sheets (вкладки settings, users, codes, sessions, documents, roles, log, notifications).
- **Документи:** Google Docs у папці «Портал погодження — Робочі документи», PDF — в «Архів (PDF)».

Процес: ініціатор завантажує Word → учасники по черзі редагують (блокування) → усі погоджують (будь-яка правка/відхилення обнуляє раунд) → корпоративний секретар затверджує або повертає → посадові особи підтверджують ознайомлення (PDF + кнопка в листі) → виконавець позначає «Виконано».

`n8n/logic.js` — основна логіка (Code node «Logic»), `n8n/test_logic.js` — локальна симуляція (`node n8n/test_logic.js`).
